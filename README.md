# Mac-Linux-software-tools-installers

VERY MUCH A WORK IN PROGRESS!!

Mac and Linux software tools and installers avoiding annoying sandboxing whenever possible. Configuring and streamlining Mac and Linux.

About my systems:
I am running 3 Classic Mac Pro's (A1289) with RX580's on MacOS Sequoia, Ubuntu Linux, and Windows 11. I have a 2012 MacBook Pro and Mac Mini running Ubuintu Linux 26.

All drivers are working after a lot of configuration battles, and most of the information on the internet doesn't work, so I thought I would share. I have the RX580's working fully accelerated, all network and bluetooth drivers.

I have a lot of Mac and Linux utilities I have written, and software installer scripts.
Many help with MacOS, and with Linux on their own, but also when migrating to Linux from Mac.
Even in 2026, Linux isn't close to MacOS in many areas, setup, config, mounting and sharing drives, setting up the firewall, server, and a lot more that's simple on Mac or Windows, is not simple on Linux, and often there is no GUI software you can install to do it.
I've written scripts to handle a lot of this, and it may help others with the transition, or just day-to-day use.
Any changes, suggestions, additions, are all welcome.

I am just starting this page, so i will grow it over time.

I am using MacOS Sequoia as my main system, and Ubuntu Linux 26 as my server.
Sequoia runs great on the Mac Pros, faster than most newer Macs, but on lower models, it's unusable. Eventually, with Intel phasing out, Linux will probably be the future on my main system as well.
I have Ubuntu on my MacBook Pro and Mac Mini, as Sequoia is way to slow.
These machines run like new with Linux installed. MacOS is so bloated, it makes them unusabl.
